# API File Downloader (Demo Version)

## Purpose

This repository is a **technical showcase** of a project that automates:
- Authentication workflows with web sessions
- Retrieval of files or resources via APIs
- Retrieval of structured links such as schedules or resource indexes
- Asynchronous downloading and writing of files
- Organization of downloaded content into structured folders

⚠️ Disclaimer  
This is **not a functional version** of the original project.  
The working version is kept **in a private repository** because it relies on an external platform that cannot be shared publicly.  

The goal of this public repo is to demonstrate:
- Project structure (bots, tools, tests)
- Code quality and modular design
- Automated testing with pytest
- Logging and configuration management
- Asynchronous I/O handling
- Data extraction and organization

## Quickstart

### Requirements
- Python 3.11+

### Installation
Run the following commands:
```
make virtualenv
source .mainbot_env/bin/activate
make install
```
### Development
For development setup:

```
make install_dev
make test
```

## Notes
- This project is for **portfolio / educational purposes only**.
